# 🏦 Python Core Banking & Microfinance Loan Engine

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A lightweight, robust **Core Banking & Microfinance Engine** written in Python. Implements double-entry ledger transfers, customer deposit accounts, and reducing-balance **Equated Monthly Installment (EMI)** loan amortization schedules with principal/interest breakdown.

---

## ⚡ Highlights
- 💰 **Ledger Transfers**: Atomic account debit/credit transaction operations with balance validation.
- 📐 **EMI Calculator**: Reducing balance interest calculation with complete monthly payment amortization table.
- 🧪 **Pytest Coverage**: Unit tests included.
